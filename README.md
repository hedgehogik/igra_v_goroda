# 🏙️ Telegram-бот "Города" с AI

Бот для игры в города с искусственным интеллектом.
Поддерживает GigaChat и GPT-4o, голосовой ввод и озвучку ответов.

## Возможности

- 🎮 Игра в города с AI-соперником
- 🤖 Выбор модели: GigaChat или GPT-4o
- 🎤 Голосовой ввод городов
- 🔊 Озвучка ответов бота
- ℹ️ Информация о городах
- 👥 Мультипользовательский режим
